# Brand Assets — beklenen dosyalar

Sohbette paylaşılan görseller diske otomatik kaydedilmedi. Lütfen orijinal dosyaları bu klasöre şu adlarla ekleyin:

- `logo.png` — altın arı monogram + AGOBEE wordmark (siyah zemin)
- `wipe-military.png` — askeri seri sachet (siyah/altın)
- `wipe-daily.png` — günlük yaşam serisi sachet (bordo)
- `wipe-healthcare.png` — sağlık kurumları serisi sachet
- `wipe-outdoor.png` — dağcı/kampçı serisi sachet (koyu yeşil)
- `hotel-collection.png` — otel koleksiyonu şişeler (şampuan, duş jeli, saç kremi)

Tercihen ek olarak: logonun SVG'si, şeffaf zeminli arı monogramı, ve yüksek çözünürlüklü ürün fotoğrafları.
